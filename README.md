# FIXME issues

Found a bug in FIXME, or want something it doesn't do yet? This is the place, for the Mac app and every phone helper (iOS, Android, React Native, Flutter).

[Report a bug](https://github.com/fixme-dev/fixme-issues/issues/new?template=bug.yml) · [Ask for a feature](https://github.com/fixme-dev/fixme-issues/issues/new?template=feature.yml)

From the Mac app, **Help > Report a Bug** opens a bug report with your FIXME and macOS versions already filled in.

## Before you post

Issues here are public. Please don't paste:

- Doctor's **Copy diagnostics** report. It contains your project's folder path and your phones' names. Send it to [general@getfixme.dev](mailto:general@getfixme.dev) instead.
- Screenshots or clips of an app that isn't public yet.
- License keys, order numbers or email addresses.

For anything about your purchase or license, write to [general@getfixme.dev](mailto:general@getfixme.dev).

## Security

Please report a security problem privately: use **Report a vulnerability** on this repository's [Security tab](https://github.com/fixme-dev/fixme-issues/security), or write to [general@getfixme.dev](mailto:general@getfixme.dev).
